# Course asset guidance

Add course-specific images, documents and other static media under `public/assets/`.

- Use descriptive, lower-case filenames.
- Provide meaningful alternative text when an image conveys information. Use empty alternative text only for decorative images.
- Reference assets with root-relative paths such as `/assets/example-image.jpg` while the starter is hosted at a domain root.
- Check every source reference before deleting or replacing an asset.
- Remove assets that are no longer used by the course.
- Optimise media for its intended display size and test downloads, captions and playback where applicable.

Root-relative paths require additional configuration before the course can be hosted in a subdirectory or packaged for an LMS. See the hosting section in the project README.
